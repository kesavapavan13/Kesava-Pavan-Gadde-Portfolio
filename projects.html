ResearchChat-AI: Hybrid RAG Assistant

Tech Stack: Python | LangChain | FAISS | BM25 | Docling | Hugging Face Embeddings | Groq | Streamlit

  • Built a hybrid RAG assistant that answers questions from uploaded research paper PDFs.
  • Parsed PDFs with Docling and split them into 1500-character chunks with 300-character overlap.
  • Embedded chunks with BAAI/bge-small-en and indexed them with FAISS (dense) and BM25 (sparse) search.
  • Combined both rankings using Reciprocal Rank Fusion (k=60) to retrieve the top 4 chunks.
  • Generated context-grounded answers with Groq-hosted gpt-oss-20b to reduce hallucinations.
  • Built a Streamlit app with multi-PDF upload, retrieved chunk inspection, and response-time tracking.

House Price Prediction

Loan Default Prediction

Tech Stack: Python | Pandas | Scikit-learn | XGBoost | Imbalanced-learn | Streamlit | Joblib

  • Built a binary classification model to predict loan default on 255K+ applicant records.
  • Handled a class-imbalanced target (about 11.6% defaults) using class weights and SMOTE experiments.
  • Preprocessed data with OrdinalEncoder and StandardScaler inside a ColumnTransformer.
  • Tuned Random Forest, XGBoost, and Logistic Regression using RandomizedSearchCV and GridSearchCV.
  • Evaluated with ROC-AUC, precision, recall, and F1-score, reaching a ROC-AUC of about 0.75.
  • Deployed a Streamlit app that shows the prediction along with default probability.
